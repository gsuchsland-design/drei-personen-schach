# Drei-Personen-Schach

Schach für drei Spieler auf einem sternförmigen Brett – direkt im Browser.

**▶ Spielen:** https://gsuchsland-design.github.io/drei-personen-schach/

## Funktionen
- Brett als Davidstern mit drei Sektionen (je 4 × 8 Felder), Züge über die Brettmitte
- 2D- und 3D-Ansicht mit frei wählbarer Perspektive
- Computergegner in vier Stufen (leicht, mittel, stark, Meister)
- Sonderregeln für drei Spieler: Hilfspflicht, Matt-Sieger, Aussetzen, Punktewertung
- Zeitkontrolle pro Zug und/oder pro Partie
- Zugprotokoll mit Zurücknehmen, Speichern und Laden
- Animierte Züge, geschlagene Figuren fliegen an den Rand, Geräusche
- Spielanleitung mit interaktivem Übungsbrett

Die komplette Spielanleitung ist im Spiel über **📖 Regeln** erreichbar.
